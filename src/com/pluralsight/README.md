# Accounting Ledger App

## Description
A Java console application that tracks financial transactions, including your deposits and payments.

## Features
- Add deposits and payments
- View all transactions, deposits only, or payments only
- Reports screen with filtering options:
  - Month to Date
  - Previous Month
  - Year to Date
  - Previous Year
  - Search by Vendor
  - Custom Search

## How to Run
1. Clone the repository
2. Open the project in IntelliJ
3. Run Appjava

## Technologies Used
- Java
- File I/O (CSV)
- ArrayList, LocalDate
